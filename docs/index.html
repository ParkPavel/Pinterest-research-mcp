Локальный MVP. Интеграция ChatGPT в разработке.

Локальный MCP-коннектор для чтения авторизованных досок и пинов Pinterest.

Возвращает метаданные, медиа-ссылки и оригинальные ссылки на пины.

Открыть GitHub Документация
01

Доски и разделы

Чтение доступных авторизованному аккаунту досок и разделов с их метаданными.

02

Пины и медиа

Получение пинов, описаний и URL медиа для дальнейших исследований.

03

Источники и пагинация

Оригинальные ссылки на пины и постраничная загрузка коллекций через bookmark.

MCP-инструменты

8 инструментов

Только чтение, в пределах разрешений подключённого аккаунта. Доступ ко всему Pinterest и анализ пикселей изображений не реализованы.

pinterest_account
Информация об авторизованном аккаунте Pinterest.
pinterest_boards
Список доступных досок с пагинацией.
pinterest_board
Метаданные доски по идентификатору.
pinterest_board_pins
Пины доски, ссылки на источники и медиа.
pinterest_pins
Доступные пины аккаунта с пагинацией.
pinterest_pin
Метаданные и медиа одного пина.
pinterest_board_sections
Список разделов доски.
pinterest_section_pins
Пины выбранного раздела доски.
